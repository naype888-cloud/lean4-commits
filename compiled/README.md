# Compilés — les dépôts du profil en Lean 4

Chaque dépôt compile seul, en Lean 4 sur Mathlib, certains sur Physlib, avec les seuls axiomes standards `[propext, Classical.choice, Quot.sound]`. Une ligne par dépôt, reprise de sa propre description.

## Le théorème et ses fondations

| Dépôt | En une ligne |
|---|---|
| [`nava-robertson-schrodinger`](https://github.com/naype888-cloud/nava-robertson-schrodinger) | Le théorème principal : incertitude élémentaire dimensionnelle de Nava–Robertson–Schrödinger sur le cube ouvert NRS³ (graphe chemin, produit tensoriel d’espaces de Hilbert de dimension d) |
| [`nrs3-hidrogeno`](https://github.com/naype888-cloud/nrs3-hidrogeno) | L’atome d’hydrogène sur les sites entiers du cube, l’inégalité de Hardy, la boule de Bloch en d = 2 |
| [`nrs3-uncertainty-cone`](https://github.com/naype888-cloud/nrs3-uncertainty-cone) | La matrice de Gram d’une paire conjuguée est un quadrivecteur de Minkowski ; Robertson–Schrödinger est le cône de lumière, le quantum NRS³ la garde strictement à l’intérieur |
| [`nrs3-dark`](https://github.com/naype888-cloud/nrs3-dark) | `1 − Ω_b`, l’intérieur du quantum volumétrique |
| [`nrs3-hopf`](https://github.com/naype888-cloud/nrs3-hopf) | La boîte à quatre axes, une fibre fermée sur le cube ouvert |
